# Starjet SOC · 航班运行任务中心

基于《公务航空系统｜航班详情页 PRD + 页面线框结构》的 P0 可交互前端原型。

## 查看方式

直接用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器。

## 已覆盖的 P0 范围

- 固定航班顶部信息、当地时间/UTC 切换和 Flight Readiness
- Overview、Flight / Aircraft、Crew / Passenger
- Handling / Fuel、Permit / Slot
- Tasks、Documents、Risk Center
- Change Log / Activity 和放行判断

所有展示数据均为虚构或脱敏演示数据，不包含真实客户信息。
